# وێنەی کاڵاکان

وێنەی خۆت لێرە دابنێ (JPG، PNG یان WebP). لە `index.html`دا بەستەری وێنە بە شێوەی `images/ناوی-وێنە.jpg` بنووسە.

- `image`: وێنەی سەرەکیی دیزاین.
- `previewImages`: چوار وێنە بە ڕیز، بۆ **DESIGN**، **DETAIL**، **COLOUR** و **FIT**.

ناوی وێنە لە کۆددا دەبێت لەگەڵ ناوی فایلەکە لێرە یەکسان بێت. ناوی فایلەکان بە پیت و ژمارەی ئینگلیزی بنووسە بۆ ئەوەی بە ئاسانی بیانناسیت.

وێنەکانی کەڤەری ئایفۆنی فرۆشگا لەم فۆڵدەرەدان: `iphone-glass-silver.jpeg`، `iphone-glass-blue.jpeg`، `iphone-glass-titanium.jpeg`، `iphone-glass-bronze.jpeg`، و `iphone-glass-purple.jpeg`. هەموو کەڤەرەکان بە نرخی `$25` و گەیاندنی خۆڕایی پیشان دەدرێن.
